# Documentation

Start with the [HTTP quickstart](../README.md) to run the server and request a forecast.

- [HTTP API reference](http-api.md): request and response formats, endpoints, limits, timing and shutdown.
- [Models and checkpoints](models.md): download 5M or 28M, model dimensions and strict weight loading.
- [Forecasting and plotting](forecasting.md): CSV forecasting, Rust API options and forecast bands.
- [Development and validation](development.md): build examples, Python parity comparisons, HTTP tests and Rust setup troubleshooting.
- [Performance and profiling](performance.md): Python/Rust benchmarks, HTTP load testing, optimization experiments and Samply.
- [Architecture and implementation](architecture.md): source layout, model data flow, supported features and remaining work.

Run commands from the repository root, even when following a page in this directory.
Python commands retain the existing parent project environment (`../.venv`).
